# 할 일 관리 앱 PRD

Oct 21, 2026 · @WK Bae

## 1. Why - 목적

- 할 일을 주간 계획과 1년 목표에 연결해, 일일 실행이 장기 목표로 이어지게 한다.
- 할 일 상태 변경이 주간·연간 진행률에 자동 반영되게 한다.
- 목표와 일일 작업이 따로 노는 문제를 없앤다.

## 2. Who - Target Users

- 1년 단위 목표를 세우고 주간·일일로 쪼개 실행하려는 개인 사용자
- 할 일 진행 상태를 시각적으로 관리하고 싶은 사용자
- 일일 작업이 목표 달성에 얼마나 기여하는지 확인하고 싶은 사용자

## 3. User Flow

1. 1년 목표 생성
2. 주간 계획 생성 후 1년 목표에 연결
3. 할 일 생성 후 주간 계획에 연결 (일일 날짜 지정)
4. 보드에서 할 일 확인 (todo / doing / done)
5. Drag & Drop으로 상태 변경
6. 상태 변경 시 주간 진행률 자동 갱신
7. 주간 진행률 변경 시 1년 목표 진행률 자동 갱신
8. 목표/주간/일일 화면에서 진행 현황 확인

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **할 일 CRUD**
  - 생성: 제목, 날짜(일일), 가중치(정수 1\~5, 기본값 1), 연결할 주간 계획
  - 수정: 제목, 날짜, 가중치, 상태, 연결 주간 계획
  - 삭제: 삭제 시 진행률 재계산
- **상태 관리**
  - 상태: todo / doing / done
  - 신규 할 일의 기본 상태: todo
- **Drag & Drop 상태 변경**
  - 상태 컬럼 간 카드 이동으로 상태 변경
  - 이동 즉시 저장 및 화면 반영
- **기간 구조**
  - 일일: 할 일 단위 (날짜 지정)
  - 주간: 주간 계획 (기간: 주 시작일\~종료일)
  - 1년: 연간 목표 (기간: 연도)
- **구조 연결**
  - 할 일 → 주간 계획 → 1년 목표 (상위 계층 연결 필수)
  - 하위 항목이 있는 상위 항목 삭제 시 처리 방식 확인 필요
  - 계층별 조회: 목표 → 주간 계획 → 할 일
- **주간 진행 자동 반영**
  - 주간 진행률 = done 할 일 가중치 합 / 연결된 전체 할 일 가중치 합
  - 1년 목표 진행률 = 연결된 주간 계획 진행률의 가중 평균 (주간 계획 가중치 = 소속 할 일 가중치 합)
  - 상태 변경, 할 일 추가·삭제 시 자동 재계산 (수동 입력 없음)

### P1 - 추가 기능

- 진행률 시각화 (진행 바)
- 기간별 필터 (일일 / 주간 / 연간)
- 미완료 할 일 다음 주 이동
- 목표·주간 계획별 달성 현황 요약 화면

### 확인 필요 사항

PRD 범위 밖이며 구현 전 결정이 필요하다.

- 상위 항목 삭제 시 하위 항목 처리 (함께 삭제 / 연결 해제)
- 플랫폼 (웹 / 모바일)
- 로그인 및 데이터 저장 방식
