## Entry: 2026-11-20 — npm 12 가 esbuild postinstall 차단 (렌더는 정상)
- **상황**: US-002, `remotion/`에서 `npm install` (Node 26 / npm 12.2.0, remotion 4.0.539)
- **증상**: `npm warn install-scripts 1 package had install scripts blocked because they are not covered by allowScripts: esbuild@0.28.1 (postinstall: node install.js)`
- **원인**: npm 12 기본 정책이 allowScripts 미등록 패키지의 install script 를 막음. esbuild 바이너리는 optionalDependency `@esbuild/darwin-arm64`로 이미 설치되어 postinstall 은 검증용일 뿐
- **해결**: 조치 없음. 렌더가 실패하면 `npm install-scripts approve esbuild` 후 재설치
- **검증**: `uv run pytest -q tests/test_render.py` (실제 `npx remotion render` smoke 포함) 통과

## Entry: 2026-11-20 — 텍스트 박힌 emoticon 이 원고에 없는 사실을 화면에 표시
- **상황**: review.md 기반 개선, job `sf_20261119_235389` 결과 `output/ret.mp4` 검토 (branch `feat/md2short-v1`)
- **증상**: "지난 금요일 미국 증시가 강하게 상승 마감했습니다." 구간에 `49_반도체18연속상승_강세마감.png`("18연속 / 반도체") 표시. "다우는 소폭 하락" 과 "사용자 감소" 에 울음("내 돈…") 컷. 마지막 "오늘 장 흐름도…" 에 랠리 컷
- **원인**: 구체적 사실 컷에 범용 키워드(`상승 마감`, `강세`, `약세`)가 매핑됨. fallback 상승 트리거 `늘`이 `오늘`에 매칭. 하락 fallback pool 이 투자 손실 컷으로만 구성
- **해결**: `emoticon_map.CLAIM_TOKENS` 가드(사실 토큰이 span 원문에 있을 때만 사용), `늘`→`늘었/늘어`, `소폭 하락`→관망 컷, 하락 fallback pool 을 혼란/당황 컷 우선으로 교체, 사상최고치 컷을 상승 fallback 에서 제거
- **검증**: `uv run pytest -q` 195 passed (`test_claim_emoticon_requires_fact_in_text`, `test_mild_vs_severe_decline`, `test_oneul_is_not_rise_trigger`), 같은 job 재렌더 프레임에서 18연속 컷·오매칭 없음 확인

## Entry: 2026-11-20 — 하락 fallback 회전 위치에 따라 "내 돈…" 컷 재발
- **상황**: 위 수정 후 `uv run md2short run sample.md --voice EXAVITQu4vr4xnSDxMaL` 재실행, job `sf_20261120_3faa7f`
- **증상**: "어린이 이용 제한 기능 도입이 사용자 감소로 이어졌습니다." 에 `04_나도울고싶어_하락.png`("내 돈…") 표시
