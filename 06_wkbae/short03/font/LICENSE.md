# Font license

`NotoSansKR-Variable.ttf` is **Noto Sans KR** (variable weight 100–900),
downloaded from the Google Fonts repository
(`https://github.com/google/fonts/tree/main/ofl/notosanskr`).

It is licensed under the SIL Open Font License 1.1 — full text in `OFL.txt`.

This font is a placeholder. `font.css` exposes it under the family names
`SeoulAlrim` and `SeoulNotice`; replace the `src` URLs in `font.css` with the
real Seoul font files to switch fonts without touching Remotion code.
