## 🟠 High — 시청 경험에 바로 보이는 문제

### H1. 숫자 카드가 이모티콘 그림 속 글자를 가림
**증상**: 숫자 카드 5장 중 4장이 이모티콘 상단 문구 위에 겹침.

| 시점 | 카드 | 가려지는 그림 글자 |
| --- | --- | --- |
| ~17s | `S&P 500 종가는 7,230` | "분석 중…" |
| ~21.5s | `0.94%` | "정독 중" |
| ~32s | `3.2%` | "깜짝 성장" |
| ~47s | `18%` | "전량 매도!" |

카드 문구에 조사도 섞여 있음: `S&P 500 종가는 7,230` (`data_extract`의 index 패턴이 지수명과 숫자 사이 최대 8자를 그대로 포함함).

**개선**:
- 카드를 이미지 영역 상단(`CONTENT_TOP + 60`)이 아니라 이모티콘 아래쪽이나 측면으로 옮김. 또는 카드가 떠 있는 동안 이모티콘을 살짝 축소/하강시킴.
- index 카드는 조사·서술어를 제거하고 `S&P 500 7,230` 형식으로 정규화함.

### H2. 아웃트로가 마지막 두 문장을 덮음
**증상**: 아웃트로(2.6s)가 53.0s에 시작함. 그런데 "어린이 이용 제한 기능 도입이 사용자 감소로 이어졌습니다."가 53.3s까지 읽히고 있고, 마지막 문장 "오늘 브리핑은 여기까지입니다."(53.7–55.2s)는 자막이 overlay 뒤에 가려져 거의 보이지 않음.

**원인**: 영상 길이 = 오디오 길이라는 QC 제약 때문에, 아웃트로가 음성 위에 겹치는 방식밖에 없음.

**개선**:
- 아웃트로 시작을 마지막 자막 segment 시작(`captionSegments[-1].startMs`, words.json 기준)에 맞추고, overlay를 하단 자막 띠 위까지만 덮어 마지막 자막은 보이게 함.
- 또는 TTS 오디오 뒤에 1.5–2s 무음 tail을 붙여 아웃트로 전용 구간을 확보함. 이 경우 QC `sync_last_word_vs_audio`(±1000ms) 기준을 "outro tail 포함"으로 함께 조정해야 함.

### H3. 화면의 약 48%가 검은 띠
**증상**: 상단 470px(빈 여백 250px + 로고 220px)와 하단 460px가 검정임. 실제 이미지 영역은 990px(52%)임. 로고 위 250px는 완전히 비어 있음. 자막은 약 1500–1680px에 있어 여전히 화면 하단 22% 안이므로 Shorts 제목·채널명 overlay와 일부 겹침.

**개선**:
- 상단 빈 여백을 줄이고(예: 250px → 140px) 그만큼 이미지 영역을 키움.
- 이모티콘 크기(현재 820px)를 키우고, 자막을 이미지 영역 하단에 반투명 배경으로 겹쳐 올림.
- `layout.ts`, `architecture.md` §2.3/§5.8의 레이아웃 수치를 함께 갱신해야 함.

### H4. 회사 로고가 우측 UI 버튼 영역에 있고 노출이 짧음
**증상**: Apple/SanDisk/Oracle/Roblox 로고가 화면 오른쪽 끝(x≈840–1040, y≈1170–1370)에 1.5초만 나옴. 이 위치는 Shorts의 좋아요/댓글 버튼 열과 겹침. 로고 이미지도 아직 placeholder(색 박스 + 영문 글자)임.

**개선**:
- 로고를 좌측 하단이나 숫자 카드 옆으로 옮기고, 노출을 해당 문장 끝까지(문장 segment 길이) 늘림.
- 실제 로고 PNG로 교체함. 상표 사용 가능 여부도 확인이 필요함.

### H5. 첫 2.7초가 날짜 카드뿐
**증상**: 0–2.06s는 spoken "11월 20일 데이브리핑입니다." + 날짜 카드이고, 훅 "5주 연속 상승으로 2024년 이후 최장 랠리"는 2.68s에 시작함. 숏폼은 첫 1–2초에 이탈이 결정됨.

**개선**:
- spoken 날짜 문구를 없애거나 끝으로 옮기고, 날짜 카드는 훅 문장과 동시에 작게(상단 배지) 노출함.
- 날짜 카드도 렌더 날짜(11월 20일)가 아니라 시장 기준일(원고의 "지난 금요일")을 쓰는 편이 정확함.

## 🟡 Medium — 완성도

### M1. 자막에서 숫자가 강조되지 않음
**증상**: 강조색은 이모티콘 키워드(상승·하락·성과·AI 등)에만 적용되고, `7,230`, `0.94%`, `3.2%`, `8%`, `18%`는 흰색임. 숏폼 데이터 영상에서 가장 중요한 정보가 묻힘.

**개선**: 숫자 토큰(퍼센트·포인트·금액·지수 값)도 강조함. 색은 같은 문장의 등락 방향(`tone`)을 따름: 상승은 노랑/초록, 하락은 빨강.

### M2. hook 사실이 본문에서 다시 반복됨
**증상**: 1번째 문장 "5주 연속 상승으로 … 최장 랠리"와 7번째 문장 "핵심은 이번 랠리가 다섯 주 동안 이어지고 있다는 점입니다."가 같은 사실임. 표기도 "5주"/"다섯 주"로 갈림. 원고에 "핵심은 '5주 연속 상승'" 줄이 있어서 "정보 보존" 규칙과 "반복 금지" 규칙이 충돌한 결과로 보임.

**개선**: 프롬프트에 "원문이 hook 사실을 재강조하는 줄은 hook에 합치고 본문에서 생략" 규칙을 넣음. 숫자 표기는 아라비아 숫자로 통일함.

### M3. 이모티콘 매칭이 약한 구간

| 시점 | 문장 | 현재 컷 | 문제 |
| --- | --- | --- | --- |
| ~20.6s | 나스닥은 0.94% 상승했습니다. | 정독중 | 상승 컷이 앞에서 다 쓰여서 중립 컷으로 밀림 |
| ~36.9s | 오라클이 미 국방부 AI 네트워크 프로젝트에 공식 합류했습니다. | 승인 도장 | 군복 + AI 서버 + 계약서 그림인 "AI 계약" 컷이 이 문장에 더 맞는데, 다음 문장으로 밀림 (`공식 합류` 4자 > `AI` 2자 점수) |
| ~53.7s | 오늘 브리핑은 여기까지입니다. | 분석중 (2번째) | 마무리 문장 전용 컷이 없음 |

중복은 랠리 ×2, 분석중 ×2임.

**개선**:
- 키워드 점수에 "이미지가 묘사하는 대상" 가중치를 둠(예: 기업명 + AI 문장 → AI 계약 컷).
- 상승 fallback pool을 넓힘(현재 3종).
- 마무리 문장(cta)에는 인사/구독 계열 컷을 고정함.

### M4. 연출이 단조로움
**증상**:
- 모든 컷이 같은 레이아웃(중앙 이모티콘 + 8% Ken Burns)임.
- 지수 3개(S&P/나스닥/다우)를 비교하는 시각화가 없음.
- LRA 2.2 LU에 무음 구간이 0회여서 배경음악이나 효과음이 없는 것으로 보임(측정 기반 추정, 직접 청취 안 함).

**개선**:
- 지수 문장 구간에 3개 지수 등락 카드(▲/▼ + 수치)를 넣음.
- 숫자 카드 등장 시 짧은 효과음, 나레이션 아래 -20dB 수준의 BGM 덕킹을 넣음.

### M5. 데이터 출처·기준일 없음
**증상**: 면책 문구는 있지만 "언제 기준, 어디 데이터"인지가 없음.

**개선**: 아웃트로나 하단에 작은 글씨로 `기준: 5월 22일(금) 미국 증시 종가`를 표시함. 원고 front-matter나 첫 줄에서 기준일을 받을 수 있게 함.

## 🟢 Low — 다듬기

- **L1. 면책 문구 크기**: 36px는 모바일에서 읽기 어려움. 40–44px + 대비 상향을 권장함.
- **L2. 음량**: -15.7 LUFS / TP -4.3 dBFS로 문제없는 수준. -14 LUFS로 맞추면 다른 숏폼과 체감 음량이 같아짐(`loudnorm` 후처리).
- **L3. 길이**: 55.6s로 60초 상한에 가까움. H5에서 spoken 날짜를 빼면 약 2.5초 줄어듦.

## 잘 된 점 (유지)

- 원고에 없는 사실을 그림이 주장하지 않음. 소폭 하락(관망) / 급락(전량매도) / 사용자 감소(머리아파) 구분이 맞음.
- 종목·지수가 문장 단위로 분리되어 자막과 컷이 문장마다 바뀜(평균 3.4초/컷).
- 자막: 어절 단위 줄바꿈, 키워드만 강조, 하락은 빨강. 18% 숫자 카드도 빨강.
- crossfade 전환으로 빈 화면 없음. 오프닝 직후 공백 없음.
- 새 헤더 로고가 상단 띠 중앙에 선명하게 들어감.
- 무음 0.35s 이상 구간 없음, 1.5s 이상 정지 프레임 없음, QC 통과(tail 349ms / render 11ms).
