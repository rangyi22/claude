# `06/output/ret.mp4` 영상 개선점 리뷰

> 분석 대상: `../../06/output/ret.mp4` — 1080×1920 / 30fps / 48.85s / H.264(`yuvj420p`, 1.67 Mbps) + AAC 48kHz stereo(317 kbps), 12.2 MB
> 입력 원고: `../../06/sample.md` (16문장)
> 작성일: 2026-11-20

## 분석 방법과 한계

- 2초 간격 프레임 25장 + 의심 구간(25~27s, 31~34s, 47~49s) 0.5초 간격 클로즈업, 1080p 원본 프레임 확인.
- `ffmpeg` 측정: `ebur128`(라우드니스), `silencedetect`(-40dB/0.4s), `freezedetect`(2s), scene 변화(>0.25).
- **음성은 직접 청취하지 않음.** TTS 발음·억양·BGM 품질은 평가 범위 밖이며, 오디오 항목은 수치 측정 결과만 근거로 함.
- 타임스탬프는 샘플링 기준이므로 ±0.5s 오차 가능.

## 🔴 Critical — 배포 전 수정

### C1. 자막이 한국어 어절 중간에서 줄바꿈됨

**증상** (2줄 자막 대부분에서 발생):

| 시점 | 화면 표시 |
| --- | --- |
| ~2s | `…강하게 상승 마감했` / `습니다.` |
| ~6s | `…최장 랠리입` / `니다.` |
| ~12s | `…두 번째로 좋은 성과입` / `니다.` |
| ~27s | `애플, 호실적으로 3.2% 상승했습` / `니다.` |
| ~34s | `…프로젝트에 공식 합` / `류했습니다.` ← 단어 자체가 쪼개짐 |
| ~38s | `…매출 사이클에 진입` / `한 신호입니다.` |
| ~42s | `…사용자 감소` / `로 이어졌습니다.` |

**영향**: 가독성 저하가 가장 크게 체감되는 결함. "합 / 류했습니다"는 오탈자로 보임.

**개선**:

- 자막 컨테이너 CSS에 `word-break: keep-all; overflow-wrap: break-word;` 적용 (한국어는 기본값이 글자 단위 줄바꿈).
- 근본적으로는 자막 segment 생성 단계에서 어절(공백) 경계 기준으로 줄을 나눠 `props.json`에 줄 단위로 넘기고, Remotion은 받은 줄 그대로만 렌더링.
- 2줄 균형 배치(윗줄이 꽉 차고 아랫줄 1어절만 남는 "고아 줄" 방지)를 함께 적용.

### C2. 비주얼이 원고에 없는 사실을 주장함 (금융 콘텐츠 정확성)

**증상**:

- ~18–21s `나스닥은 0.94% 상승했습니다.` 구간에 **"사상 최고치 / S&P·나스닥 / All-Time High"** 이모티콘. 원고에는 사상 최고치 언급이 없음.
- ~22s `다우는 소폭 하락했습니다.`에 울면서 "내 돈…" 하는 이모티콘 → "소폭" 하락 대비 과장.
- ~42–48s `어린이 이용 제한 기능 도입이 사용자 감소로…`(로블록스)에 **"소비심리 추락"** → 원고와 무관한 거시경제 메시지.

**영향**: 시청자는 화면 텍스트를 사실로 받아들임. 증시 브리핑에서 근거 없는 "사상 최고치"는 신뢰도와 컴플라이언스 리스크.

**개선**:

- 이모티콘에 **텍스트가 박힌 경우**(사상 최고치, 소비심리 추락, AI 계약 등) 해당 키워드가 원고 문장에 실제 존재할 때만 매칭 허용. 아니면 텍스트 없는 중립 이모티콘으로 fallback.
- 하락 강도별 이모티콘 분리: 소폭 하락(중립·걱정) vs 급락(울음). 현재는 다우(소폭)와 로블록스(-18%)에 같은 울음 이미지가 쓰임.

## 🟠 High — 시청 완료율·노출에 직접 영향

### H1. 자막이 YouTube Shorts / Reels UI 가림 영역에 위치

**증상**: 1080×1920 기준 레이아웃은 헤더 0–220px, 이미지 220–1540px, **자막 1540–1680px**, 빈 검정 1680–1920px. 자막이 정확히 하단 약 20%(Shorts 제목·채널명·설명이 덮는 영역)에 들어감.

**개선**:

- 자막 baseline을 약 1350–1450px로 올리고, 이미지 영역 하단과 겹치게 반투명 배경 처리.
- 하단 240px 검정 여백은 UI에 어차피 가려지므로 비워 두되, 그 위로 콘텐츠를 배치.
- 우측 120px도 좋아요/댓글 버튼 영역이므로 핵심 텍스트 배치 금지.

### H2. 같은 이모티콘이 오래·반복 노출됨

**증상**:

- "랠리" 이모티콘이 ~6–17s 약 11초 연속(3개 문장: 5주 연속 상승 / 1950년 이후 / S&P 500 7,230) + ~24–27s 재등장 → **전체 48.9초 중 약 14초(≈29%)**.
- 울음 이모티콘이 다우(~22s)와 로블록스(~40s)에 재사용.
- scene 변화 > 0.25 검출 0회: 모든 전환이 부드러운 페이드라 시각적 리듬감이 약함.

**개선**:

- 문장(자막 segment)당 이모티콘 1개를 원칙으로 하고, 동일 파일은 영상 내 1회만 쓰도록 사용 이력 기반 중복 제거.
- 숫자 문장(S&P 500 7,230 등)은 이모티콘 대신 H3의 숫자 카드로 대체해 반복 자체를 줄임.
- 컷 길이 목표 2–4초.

### H3. 숏폼의 핵심 무기인 숫자가 자막 색상 강조뿐

**증상**: `7,230`, `0.94%`, `3.2%`, `8%`, `18%`가 하단 작은 자막의 색상 강조로만 표시됨. 화면 중앙의 큰 시각 요소는 숫자와 무관한 일러스트.

**개선**:

- 수치 문장 구간에 이미지 영역 상단/중앙 오버레이로 대형 숫자 카드(예: `S&P 500 7,230`, `NASDAQ +0.94%`, `RBLX −18%`) 노출.
- 상승=초록 / 하락=빨강 색상 규칙은 현재 자막에서 잘 지켜지고 있으므로 카드에도 동일 적용.

### H4. 오디오 라우드니스가 너무 낮음

**측정**: Integrated **-23.0 LUFS**, True Peak -5.7 dBFS, LRA 2.3 LU.

**영향**: -23 LUFS는 방송(EBU R128) 기준. 모바일 숏폼 플랫폼은 약 -14 LUFS를 기준으로 큰 소리만 낮추고 작은 소리는 키우지 않으므로, 다른 숏폼 대비 확연히 작게 들림.

**개선**: 최종 후처리에서 `loudnorm=I=-14:TP=-1.0:LRA=7` (2-pass 권장).

### H5. 첫 1–2초 훅이 약함

**증상**: 0s는 회색으로 dim 처리된 "정독 중" 호랑이 위에 `5월 25일 데이브리핑` 카드. 이어서 첫 문장은 "지난 금요일 미국 증시, 강하게 상승 마감했습니다." 원고에서 가장 강한 사실(5주 연속, 2024년 이후 최장 랠리)은 ~6s에야 등장.

**개선**:

- 대본 생성 시 가장 자극적인 수치/사실을 첫 문장으로 재배치 (예: "미국 증시, 5주 연속 상승! 2024년 이후 최장 랠리입니다.").
- 오프닝 카드는 첫 문장 자막·비주얼과 동시에 짧게 겹쳐 노출(데드 타임 0).
- 오프닝 배경의 반쯤 가려진 "정독 중" 이모티콘은 카드와 겹쳐 지저분하므로 단색/블러 배경으로 교체.

## 🟡 Medium — 완성도

### M1. 2줄 자막 위에 잘린 회색 pill 배경이 보임

**증상**: 2줄 자막일 때(~2s, ~6s, ~27s, ~38s, ~42s) 자막 상단 약 1515–1540px에 회색 둥근 배경 일부가 이미지 영역 위로 삐져나오고, 아래쪽은 검정 밴드에 가려짐. 1줄 자막에는 배경 자체가 없음.

**개선**: 자막 배경을 줄 수와 관계없이 일관되게(항상 있음 또는 항상 없음) 그리고 텍스트 박스 전체를 감싸도록 수정. z-index·overflow 확인.

### M2. 자막 폰트 크기가 문장 길이에 따라 들쭉날쭉

**증상**: 긴 문장(~34s 오라클, ~12s 1950년)은 자동 축소되어 짧은 문장(~30s 샌디스크)보다 눈에 띄게 작음. 기본 크기도 1080 폭 기준 약 50px로 숏폼 평균(60–80px)보다 작음.

**개선**: 폰트 크기 고정(64–72px) + 넘치면 축소 대신 segment를 더 짧게 분할.

### M3. 자막 공백 구간

**증상**: ~33s 샌디스크 문장이 끝난 뒤 오라클 문장 시작 전까지 자막 없음(약 0.5s 이상). 이모티콘만 남아 화면이 비어 보임.

**개선**: 다음 segment 시작까지 직전 자막을 유지하거나(gap ≤ 700ms), `words.json`의 다음 단어 start를 다음 자막 시작 기준으로 사용.

### M4. 흰색 경유(fade-through-white) 전환으로 빈 화면 순간 발생

**증상**: ~26–27s "랠리" → "깜짝 성장" 전환 시 이미지가 흰 배경으로 사라졌다가 나타나, 2초 샘플 프레임에서 이미지 영역이 거의 빈 흰 화면으로 잡힘.

**개선**: 이전/다음 이미지를 겹치는 crossfade(150–250ms) 또는 짧은 scale-pop 전환으로 교체.

### M5. 아웃트로/CTA 없음

**증상**: 마지막 문장(~42–48s) 이후 이모티콘이 페이드아웃되며 종료. 구독/다음 영상 유도 없음.

**개선**: 마지막 1.5–2초에 구독 CTA 또는 "내일 브리핑에서 만나요" 카드. 반복 재생(loop) 시 첫 프레임과 자연스럽게 이어지는 구성도 고려.

### M6. 강조 범위에 조사가 포함됨

**증상**: `'5주 연속 상승'이라는`, `애플, 호실적으로 3.2%`처럼 강조색이 조사·부사까지 포함.

**개선**: 강조 대상은 명사구·숫자 토큰까지만, 조사(`이라는`, `으로`, `은/는`)는 기본색.

## 🟢 Low — 기술 사양

### L1. 픽셀 포맷 `yuvj420p` (full range)

일부 플레이어/플랫폼 재인코딩에서 색이 뜨거나 대비가 변할 수 있음. 최종 인코딩에 `-pix_fmt yuv420p -color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709` 지정.

### L2. 오디오 비트레이트 과다

음성 위주 콘텐츠에 AAC 317 kbps는 과함. 128–192 kbps로 충분하며 파일 크기 절감.

## 잘 된 점 (유지)

- 상승=초록 / 하락=빨강 자막 색상 규칙이 일관됨 (`나스닥은 0.94%` 초록, `다우는` 빨강, `로블록스, 18%` 빨강).

- 무음 구간(-40dB, 0.4s 이상) 없음, 2초 이상 완전 정지 프레임 없음.

## 우선순위 중간

1. **마무리 컷이 없습니다.** 마지막 문장 "오늘 장 흐름도 주목하시기 바랍니다." 뒤에 구독이나 팔로우 유도, 내일 예고 같은 아웃트로가 없습니다.
2. **화면 비율 배분이 아쉽습니다.** 상단 로고 띠와 하단 검은 자막 영역이 커서 이미지가 화면의 약 40%만 씁니다. 하단 자막은 쇼츠 앱의 UI(제목, 버튼)에 가려질 수 있으니, 자막을 중앙에서 약간 아래로 올리고 이미지를 키우는 방안을 검토하세요.
3. **로고 워터마크가 계속 큽니다.** 상단 "MD2SHORT" 로고가 전 구간 같은 크기로 노출됩니다. 크기를 줄이거나 반투명으로 바꿔 시선을 덜 뺏게 하면 좋습니다.
4. **스티커 배경이 완전히 투명하지 않습니다.** 이미지 주변에 흰색 계열 사각 박스 경계가 약하게 보이는 컷이 있습니다. 투명 PNG로 바꾸거나 배경을 통일하세요.
5. **기업 로고 표기가 중복됩니다.** Apple, SanDisk 로고 박스 아래에 같은 이름의 텍스트가 한 번 더 나옵니다. 하나만 남기세요. 또 실제 기업 로고를 쓸 때는 저작권과 상표 사용 여부도 확인이 필요합니다.
6. **연출 변화가 적습니다.** 컷 전환 감지 기준(임계값 0.2)으로 큰 장면 전환이 2번뿐이었습니다. 문장마다 약한 줌, 슬라이드 인, 숫자 카운트업 같은 모션을 넣으면 정적인 느낌이 줄어듭니다.

## 우선순위 낮음 (다듬기)

 1. **자막 강조색이 일관적이지 않습니다.** 노란색 강조(상승, 호실적, 급등)는 좋은데, 자막이 나오는 동안 앞부분은 흰색, 뒷부분은 회색으로 바뀌는 듯한 컷이 있어 가독성이 흔들립니다. 읽는 동안은 같은 밝기를 유지하세요. 하락 관련 단어에는 빨강, 파랑 같은 별도 색을 쓰면 직관적입니다.
 2. **음량은 대체로 양호하나 약간 큽니다.** 통합 음량이 -15.7 LUFS, 피크가 -3.5 dBFS입니다. 유튜브 기준 -14 LUFS 안팎이라 문제는 없습니다. 다만 배경음악이 있다면 내레이션과의 볼륨 차이를 따로 확인하세요.
 3. **무음 구간은 짧아서 문제없습니다.** 0.4~0.5초짜리가 3번(약 33초, 36초, 41초) 있습니다. 호흡으로 자연스러운 수준입니다.
 4. **영상 용량이 큽니다.** 비트레이트가 약 2.5Mbps, 파일은 18MB입니다. 업로드에는 문제없지만, 배포용으로는 CRF 조정으로 줄일 수 있습니다.
